# Contribute to the documentation

Thanks for helping improve the Buburuza docs.

## Ways to contribute

- **Fix or improve a page** — open a PR with the change.
- **Add a guide** — check that it covers a real, shipped feature; the docs describe what exists today, not plans.
- **Report an issue** — describe the problem and link the page.

## Guidelines

- All content is written in English.
- Keep pages focused: one page, one topic.
- Use sentence case for headings and active voice.
- Describe the product as it works today — do not add speculative features, internal identifiers, or anything not ready for public view.
- Pull requests run a safety check; they are reviewed by the code owners listed in `CODEOWNERS`.
