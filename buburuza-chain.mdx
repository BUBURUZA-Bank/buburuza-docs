It processes over 40,000 transactions per second, finalizes blocks every 250 milliseconds, and charges less than $$0.001 per transaction. ## What Buburuza-Chain is

Buburuza-Chain is an Arbitrum Orbit Layer 3 (L3) blockchain — meaning it sits on top of Arbitrum (L2), which in turn settles to Ethereum (L1). This layered architecture lets Buburuza-Chain inherit Ethereum's battle-tested security while achieving the throughput and cost structure that mainstream financial services demand.

<Note>
  Buburuza-Chain is fully EVM-compatible, which means any smart contract or developer tool built for Ethereum works natively here.
</Note>

## Security model

Buburuza-Chain uses an **optimistic rollup** architecture. Here's how security works across the three layers:

<AccordionGroup>
  <Accordion title="Ethereum L1 — the security anchor">
    Ethereum provides the ultimate source of truth. All state eventually settles here, backed by the largest decentralized validator network in existence.
  </Accordion>

  <Accordion title="Arbitrum L2 — the intermediate layer">
    Arbitrum's established validator network and fraud-proof system sit between Buburuza-Chain and Ethereum. Invalid state transitions on Buburuza-Chain can be challenged and reversed at this layer.
  </Accordion>

  <Accordion title="Buburuza-Chain L3 — financial-grade enhancements">
    Additional measures specific to financial applications sit at the L3 level, including emergency pause capabilities that governance can trigger if a vulnerability is discovered.
  </Accordion>
</AccordionGroup>

### Sequencer model

Transactions on Buburuza-Chain are ordered and batched by sequencers before being posted to Arbitrum L2.

- **Primary sequencer** — operated by the Buburuza Foundation, processing transactions with minimal latency.
- **Backup sequencers** — 5–10 independent operators, each bonding a minimum of 100,000 \$BUB as collateral. If the primary sequencer goes offline, backups take over automatically.
- **Fraud proofs** — Arbitrum's challenge mechanism means any invalid block can be disputed and reversed during the challenge window.

## Bridge architecture

Moving assets to and from Buburuza-Chain is straightforward. The table below summarizes deposit and withdrawal times for each path.

| Route | Direction | Time | Security |
| --- | --- | --- | --- |
| Arbitrum L2 → Buburuza-Chain L3 | Deposit | 1–2 minutes | Native Arbitrum bridge |
| Buburuza-Chain L3 → Arbitrum L2 | Withdrawal | ~15 minutes | Optimistic rollup challenge period |
| Ethereum Mainnet | Both | Variable | Via Arbitrum's mainnet bridge |
| Base / Optimism | Both | Variable | Third-party aggregators (Socket, Across) |
| Bitcoin (wrapped) | Inbound | Variable | Custodian wrap (e.g. BitGo) |

<Warning>
  The ~15-minute withdrawal time from L3 to L2 is a security feature, not a delay. The challenge period allows invalid state transitions to be detected and reversed before funds leave the chain.
</Warning>

### Bridge security

- **Time delays** protect against malicious actors attempting to withdraw funds based on invalid state.
- **Multi-signature controls** require multiple authorized signatures for critical bridge operations.
- **Emergency pause mechanisms** allow governance to halt bridge activity if a vulnerability is discovered.
- **Insurance coverage** from decentralized insurance protocols covers bridge operations.

## Smart contract infrastructure

Buburuza-Chain's core financial logic lives in a set of audited smart contracts.

<Tabs>
  <Tab title="$BUB token contract">
    The \$BUB token is a standard ERC-20 contract with additional capabilities:

    - **Burn functionality** — deflationary mechanisms are built in and all burns are publicly verifiable on-chain.
    - **Governance integration** — token holders can vote directly or delegate their voting power.
    - **Bridge compatibility** — \$BUB moves seamlessly between L2 and L3 via the native bridge.

  <Tab title="Stablecoin contracts">
    USDB and EURB are wrapped versions of Circle's USDC and EURC, maintaining 1:1 backing:

    - **Collateral tracking** — real-time on-chain verification of reserves, with monthly independent attestations.
    - **Automated minting** — USDB/EURB is issued automatically when verified collateral is deposited.
    - **Instant redemption** — burn USDB/EURB to receive the underlying USDC/EURC with minimal fees.
  </Tab>
  <Tab title="Account abstraction (ERC-4337)">
    Buburuza implements ERC-4337 account abstraction to make crypto wallets feel like normal bank accounts:

    - **Social recovery** — recover your account through trusted contacts without seed phrases.
    - **Flexible fee payment** — pay gas in \$BUB or approved stablecoins — no need to hold ETH.
    - **Batch transactions** — combine multiple operations into a single user action.
    - **Session keys** — grant temporary permissions to DApps without exposing your main keys.
  </Tab>

## Governance overview

Buburuza-Chain is governed by \$BUB token holders through a DAO structure. Governance covers:

- **Protocol parameters** — fee splits, block size limits, gas price floors and ceilings.
- **Sequencer management** — adding or removing network operators and setting performance standards.
- **Treasury allocation** — how community funds are deployed for development, grants, and partnerships.
- **Emergency actions** — rapid response capabilities when security incidents arise.

The protocol is progressing through three phases toward full decentralization:

1. **Phase 1** — Buburuza Foundation maintains upgrade authority with community input.
2. **Phase 2** — A governance council with token holder representation decides major changes.
3. **Phase 3** — Full on-chain governance for all protocol changes, with a security multisig retained for emergencies.

<Tip>
  You don't need to be an active governance participant to benefit from the DAO. Every vote that improves the protocol improves the platform you use every day.
</Tip>
