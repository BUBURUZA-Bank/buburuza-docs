# Authentication API

All authentication lives under `/api/v1/auth`. Identity is owned by the auth service; app endpoints verify the issued tokens locally against the published JWKS (`/.well-known/jwks.json`, RS256).

## Signup (passwordless)

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| POST | `/auth/sign-up/email` | — | Start signup; sends a one-time code |
| POST | `/auth/sign-up/email/confirmation` | `X-Registration-Token` | Confirm the code; returns the registration token for the next step |
| POST | `/auth/sign-up/email/resend` | `X-Registration-Token` | Resend the code |
| POST | `/auth/sign-up/referral` | — | Record a referral code during signup |
| GET | `/auth/sign-up/state` | — | Current signup step (e.g. resuming on another device) |
| POST | `/auth/sign-up/totp/enroll` | `X-Registration-Token` | Fallback credential: TOTP enrollment |
| POST | `/auth/sign-up/totp/confirm` | `X-Registration-Token` | Confirm TOTP → `SignupSession` |
| POST | `/auth/webauthn/register/options` | `X-Registration-Token` | Passkey registration options (`publicKey`) |
| POST | `/auth/webauthn/register/verify` | `X-Registration-Token` | Verify attestation → `SignupSession` |

After the last step you hold an access token and an authenticated session.

## Login

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| POST | `/auth/webauthn/login/options` | — | Passkey login options |
| POST | `/auth/webauthn/login/verify` | — | Verify assertion → `Session` |
| POST | `/auth/login/email` | — | Request an email login code |
| POST | `/auth/login/email/confirmation` | — | Confirm → `Session`, or `mfa_required` when MFA is on |
| POST | `/auth/login/mfa` | `mfa_token` in body | MFA step-up to complete login |
| POST | `/auth/login/recovery-code` | — | Sign in with a recovery code |

## Sessions

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| POST | `/auth/token/refresh` | refresh cookie | New access token; rotates the cookie |
| POST | `/auth/logout` | Bearer | End the current session |
| GET | `/auth/sessions` | Bearer | List active sessions (`is_current` marks this device) |
| DELETE | `/auth/sessions/{session_id}` | Bearer | Revoke one session |
| DELETE | `/auth/sessions` | Bearer | Revoke every session |

The refresh token never appears in request or response bodies: it lives in an HttpOnly cookie scoped to the auth service. On refresh the cookie is rotated via `Set-Cookie`.

## MFA (post-login, optional)

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| POST | `/auth/mfa/enroll` | Bearer | Enable TOTP MFA for logins |
| POST | `/auth/mfa/confirm` | Bearer | Confirm enrollment |

<Note>
Signup-time TOTP (the credential fallback) uses `/auth/sign-up/totp/*` — not `/auth/mfa/*`. Post-login MFA is a separate, optional factor.
</Note>

## Passkey management

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/auth/webauthn/passkeys` | Bearer + refresh cookie | List the user's passkeys |
| POST | `/auth/webauthn/passkeys/enroll/options` | Bearer + refresh cookie | Options for adding a passkey (`enroll_token`) |
| POST | `/auth/webauthn/passkeys/enroll/verify` | Bearer | Submit the attestation |
| DELETE | `/auth/webauthn/passkeys/{id}` | Bearer + refresh cookie | Remove a passkey |

## Profile (self)

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/auth/me` | Bearer | Current user |
| PATCH | `/auth/me/profile` | Bearer | Update `first_name`, `last_name` |

The company name is updated separately through [Onboarding](/api/onboarding).

## Error codes (auth)

| HTTP | Code | When |
| --- | --- | --- |
| 422 | `ValidationError` | Malformed input, expired/invalid tokens or codes |
| 404 | `session_not_found` | Session id does not belong to the user |
| 409 | `passkey_management_unavailable` | No usable refresh token for passkey management |
| 403 | `passkey_management_forbidden` | Provider token lacks the required scope |
| 404 | `passkey_not_found` | Unknown passkey id |
| 422 | `passkey_enroll_token_invalid` / `enrollment_expired` / `webauthn_verification_failed` | Passkey ceremony failures |
