The Buburuza Developer Platform gives you a single API surface to embed AI-native banking into any application. Built on a Layer 3 blockchain and powered by the Intelligent Engine B1, it delivers enterprise-grade financial services — from multi-currency wallets to smart-contract deployment — with the simplicity of modern REST APIs.

<Warning>
  **Developer Preview** — The Buburuza API platform is not yet available for public use. This documentation describes the planned API structure and capabilities. Early access opens to select partners in **Q1 2026**. Contact [developers@buburuza.com](mailto:developers@buburuza.com) to join the waitlist.
</Warning>

## Core services

The platform exposes six primary API domains, each covering a distinct area of financial functionality.

| Service | Description |
| --- | --- |
| **Authentication API** | JWT-based authentication with biometric support |
| **Account Management API** | User accounts, profiles, and KYC verification |
| **Transaction API** | Payments, transfers, and transaction history |
| **Card Services API** | Card lifecycle management and transaction processing |
| **Investment API** | Trading, portfolio management, and market data |
| **AI Services API** | Natural language processing and intelligent automation |

The platform also exposes blockchain-specific APIs: the **Buburuza-Chain API** for direct Layer 3 interaction, the **Smart Contract API** for contract deployment and interaction, the **Token API** for \$BUB and stablecoin operations, and the **DeFi Bridge API** for connecting to external protocols.

## Developer tools

You have access to a full set of tools to build, test, and ship integrations faster.

- **SDKs** — Native libraries for JavaScript/TypeScript (`@buburuza/sdk`), Python (`buburuza-python`), Java (`com.buburuza:buburuza-java`), iOS Swift (`BuburuzaSDK`), Android Kotlin (`buburuza-android`), and React Native (`@buburuza/react-native`)
- **Webhooks** — Real-time event notifications pushed to your endpoint for transactions, KYC events, balance updates, and more
- **Sandbox environment** — A fully isolated testing environment with synthetic data, test card numbers, and scenario simulation
- **Developer Dashboard** — Manage API keys, monitor usage analytics, and browse the interactive API explorer
- **CLI tools** — Command-line interface for common operations
- **VS Code extension** — IntelliSense and code snippets for Buburuza APIs
- **Postman collection** — Pre-configured API requests ready to import
