The Buburuza Core Banking API gives you programmatic access to accounts, transactions, balances, and multi-currency operations. Every transaction is automatically written to the Buburuza-Chain L3 blockchain for an immutable audit trail. All monetary amounts are expressed in the smallest currency unit (cents for USD, pence for GBP, and so on).

<Note>
  You need the `accounts:read`, `accounts:write`, `transactions:read`, or `transactions:write` scope depending on the operations you perform. See the [Authentication](/api/authentication) page for details on requesting scopes.
</Note>

## Accounts API

### Create account

**POST** `/v1/accounts`

Create a new bank account for an existing customer. You can create checking, savings, or business accounts. The `initialDeposit` funds the account at creation time.

#### Request parameters

<ParamField body="customerId" type="string" required>
  The ID of the customer who will own this account.
</ParamField>

<ParamField body="type" type="string" required>
  Account type: `checking`, `savings`, or `business`.
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO 4217 currency code (e.g. `USD`, `EUR`, `GBP`).
</ParamField>

<ParamField body="name" type="string" required>
  A human-readable label for the account.
</ParamField>

<ParamField body="initialDeposit" type="number">
  Opening deposit amount in the smallest currency unit (e.g. cents). Defaults to 0.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for storing application-specific data alongside the account.
</ParamField>

#### Example

<CodeGroup>

```javascript javascript
const account = await buburuza.accounts.create({
  customerId: 'cust_1234567890abcdef',
  type: 'checking',
  currency: 'USD',
  name: 'Primary Checking Account',
  initialDeposit: 10000,
  metadata: {
    productType: 'premium',
    openedVia: 'mobile_app'
  }
});
```

```python python
import requests

response = requests.post(
    'https://api.buburuza.com/v1/accounts',
    headers={'Authorization': f'Bearer {access_token}'},
    json={
        'customerId': 'cust_1234567890abcdef',
        'type': 'checking',
        'currency': 'USD',
        'name': 'Primary Checking Account',
        'initialDeposit': 10000,
        'metadata': {
            'productType': 'premium',
            'openedVia': 'mobile_app'
        }
    }
)
account = response.json()
```

</CodeGroup>


Return a paginated list of accounts. Filter by customer, type, status, or currency. Use `startingAfter` with the last account ID from the previous page to paginate.

<ParamField query="customerId" type="string">

<ParamField query="type" type="string">

### Set balance alerts

**POST** `/v1/accounts/{accountId}/alerts`

Configure automatic notifications for balance thresholds. You can receive alerts via email, SMS, push notification, or a webhook URL when the balance crosses the defined `threshold`.

#### Request parameters

<ParamField body="type" type="string" required>
  Alert type. Use `low_balance` to trigger when balance drops below the threshold.
</ParamField>

<ParamField body="threshold" type="number" required>
  The balance level (in the smallest currency unit) that triggers the alert.
</ParamField>

<ParamField body="notifications" type="object" required>
  Notification channels to use. Set `email`, `sms`, or `push` to `true`, and optionally provide a `webhook` URL.
</ParamField>

<ParamField body="frequency" default="immediate" type="string">
  How often to re-alert: `immediate`, `daily`, or `weekly`.
</ParamField>

```javascript balance-alert.js
const balanceAlert = await buburuza.accounts.createAlert('acc_1234567890abcdef', {
  type: 'low_balance',
  threshold: 10000, // Alert when balance drops below $100.00
  notifications: {
    email: true,
    sms: true,
    push: true,
    webhook: 'https://yourapp.com/webhooks/balance-alert'
  },
  frequency: 'immediate'
});
```

### Update account limits

**PUT** `/v1/accounts/{accountId}/limits`

Adjust spending limits and transfer controls on an account. Set `internationalTransfers` to `false` to block cross-border transactions.

```javascript update-limits.js
const updatedLimits = await buburuza.accounts.updateLimits('acc_1234567890abcdef', {
  dailyWithdrawal: 50000,     // $500.00 daily withdrawal limit
  monthlyTransfer: 1000000,   // $10,000.00 monthly transfer limit
  transactionLimit: 100000,   // $1,000.00 per transaction limit
  internationalTransfers: false,
  atmWithdrawals: true
});
```

### Configure overdraft protection

**POST** `/v1/accounts/{accountId}/overdraft`

Link a backup funding account (typically a savings account) to cover overdrafts automatically. Set `fee` to `0` to waive the overdraft fee.

```javascript overdraft.js
const overdraftSetup = await buburuza.accounts.setupOverdraft('acc_1234567890abcdef', {
  enabled: true,
  protectionAccount: 'acc_0987654321fedcba', // Savings account for coverage
  limit: 50000,                               // $500.00 overdraft limit
  fee: 0,
  notifications: {
    email: 'user@example.com',
    sms: '+1-555-0123'
  }
});
```

## Transactions API

### Create transaction

**POST** `/v1/transactions`

Create an internal transfer between Buburuza accounts or an external ACH transfer to a bank account. Use the `idempotencyKey` field to safely retry failed requests without duplicating transactions.

#### Request parameters (internal transfer)

<ParamField body="type" type="string" required>
  Transaction type. Use `transfer` for internal transfers or `ach_transfer` for external bank transfers.
</ParamField>

<ParamField body="fromAccount" type="string" required>
  The source account ID.
</ParamField>

<ParamField body="toAccount" type="string">
  The destination account ID. Required for `type: transfer`.
</ParamField>

<ParamField body="toExternalAccount" type="object">
  Required for `type: ach_transfer`. Contains `accountNumber`, `routingNumber`, `accountType`, and `holderName`.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount in the smallest currency unit (e.g. cents for USD).
</ParamField>

<ParamField body="currency" type="string" required>
  ISO 4217 currency code.
</ParamField>

<ParamField body="description" type="string">
  A human-readable description shown in the transaction history.
</ParamField>

<ParamField body="reference" type="string">
  Your internal reference ID for this transaction.
</ParamField>

<ParamField body="idempotencyKey" type="string">
  A unique key that makes this request safe to retry. If you submit the same key twice, the second call returns the original transaction instead of creating a duplicate.
</ParamField>

<ParamField body="processingSpeed" default="standard" type="string">
  For ACH transfers: `standard`, `expedited`, or `instant`.
</ParamField>

#### Example

<CodeGroup>

```javascript javascript
// Internal transfer between Buburuza accounts
const transfer = await buburuza.transactions.create({
  type: 'transfer',
  fromAccount: 'acc_1234567890abcdef',
  toAccount: 'acc_0987654321fedcba',
  amount: 5000,
  currency: 'USD',
  description: 'Transfer to savings',
  reference: 'monthly_savings_001',
  idempotencyKey: 'txn_unique_key_123'
});

// External ACH transfer
const externalTransfer = await buburuza.transactions.create({
  type: 'ach_transfer',
  fromAccount: 'acc_1234567890abcdef',
  toExternalAccount: {
    accountNumber: '9876543210',
    routingNumber: '000000000',
    accountType: 'checking',
    holderName: 'John Doe'
  },
  amount: 10000,
  currency: 'USD',
  description: 'Rent payment',
  processingSpeed: 'standard'
});
```

```python python
import requests

# Internal transfer
response = requests.post(
    'https://api.buburuza.com/v1/transactions',
    headers={'Authorization': f'Bearer {access_token}'},
    json={
        'type': 'transfer',
        'fromAccount': 'acc_1234567890abcdef',
        'toAccount': 'acc_0987654321fedcba',
        'amount': 5000,
        'currency': 'USD',
        'description': 'Transfer to savings',
        'idempotencyKey': 'txn_unique_key_123'
    }
)
transaction = response.json()
```

</CodeGroup>


### AI-powered natural language transactions

**POST** `/v1/transactions/ai-intent`

Submit a natural language transaction request and receive a structured intent with a suggested recipient, amount, and description. If the confidence score is high enough, confirm and execute with `executeAIIntent`.

#### Request parameters

<ParamField body="customerId" type="string" required>
  The customer submitting the natural language request.
</ParamField>

<ParamField body="message" type="string" required>
  The natural language transaction request (e.g. "Send \$50 to Sarah for dinner last night").
</ParamField>

<ParamField body="context" type="object">
  Optional context to improve intent resolution accuracy. Can include `recentContacts`, `currentLocation`, and `recentTransactions`.
</ParamField>

<CodeGroup>

```javascript javascript
const aiTransaction = await buburuza.transactions.processAIIntent({
  customerId: 'cust_1234567890abcdef',
  message: 'Send $50 to Sarah for dinner last night',
  context: {
    recentContacts: [
      { name: 'Sarah Johnson', accountId: 'acc_sarah_123' },
      { name: 'Mike Smith', accountId: 'acc_mike_456' }
    ],
    currentLocation: 'San Francisco, CA',
    recentTransactions: ['restaurant', 'uber', 'grocery']
  }
});

// Confirm and execute if confidence is sufficient
if (aiTransaction.confidence > 0.8) {
  const executed = await buburuza.transactions.executeAIIntent({
    intentId: aiTransaction.intentId,
    confirmations: {
      recipient: 'acc_sarah_123',
      amount: 5000,
      description: 'Dinner payment'
    }
  });
}
```

```python python
import requests

response = requests.post(
    'https://api.buburuza.com/v1/transactions/ai-intent',
    headers={'Authorization': f'Bearer {access_token}'},
    json={
        'customerId': 'cust_1234567890abcdef',
        'message': 'Send $50 to Sarah for dinner last night',
        'context': {
            'recentContacts': [
                {'name': 'Sarah Johnson', 'accountId': 'acc_sarah_123'}
            ],
            'currentLocation': 'San Francisco, CA'
        }
    }
)
intent = response.json()
```

</CodeGroup>

```json response
{
  "intentId": "intent_1234567890abcdef",

  "intent": {
    "action": "send_money",

  },
  "suggestedRecipient": {
    "name": "Sarah Johnson",
    "accountId": "acc_sarah_123",
```

### Schedule transfers

Set up a recurring or one-time future-dated transfer. For recurring transfers, specify `frequency` and `dayOfMonth`. For a one-time transfer, set `frequency: once` and provide `executeAt`.

<CodeGroup>

```javascript javascript
  currency: 'USD',
  description: 'Monthly savings',
  schedule: {
    frequency: 'monthly',
    dayOfMonth: 1,
    startDate: '2025-12-01',
    endDate: '2026-12-01'
  }
});

// One-time future transfer
const futureTransfer = await buburuza.transactions.createScheduled({
  fromAccount: 'acc_1234567890abcdef',

    accountNumber: '9876543210',
    routingNumber: '000000000'

  currency: 'USD',
  description: 'Rent payment',
  schedule: {
    frequency: 'once',
    executeAt: '2025-12-01T09:00:00Z'
  }
});
```

## Error handling

The Core Banking API returns structured errors with a `code`, `message`, and `details` object. Handle these in your transaction flows to give users clear feedback.

### Error codes

| Code | Description |
| --- | --- |
| `insufficient_funds` | The source account does not have enough available balance |
| `account_frozen` | The account is temporarily frozen and cannot process transactions |
| `daily_limit_exceeded` | The transaction would exceed the account's configured daily limit |
| `invalid_recipient` | The destination account could not be found or is invalid |
| `invalid_amount` | The amount is zero, negative, or otherwise invalid |

### Error response format

```json error-response.json
{
  "error": {
    "code": "insufficient_funds",
    "message": "The account does not have sufficient funds for this transaction",
    "details": {
      "availableBalance": 5000,
      "requestedAmount": 10000,
      "accountId": "acc_1234567890abcdef"
    },
    "requestId": "req_1234567890abcdef"
  }
}
```

### Handling errors in code

```javascript error-handling.js
try {
  const transaction = await buburuza.transactions.create({
    type: 'transfer',
    fromAccount: 'acc_1234567890abcdef',
    toAccount: 'acc_0987654321fedcba',
    amount: 1000000,
    currency: 'USD'
  });
} catch (error) {
  switch (error.code) {
    case 'insufficient_funds':
      console.log('Available:', error.details.availableBalance);
      console.log('Requested:', error.details.requestedAmount);
      break;

    case 'account_frozen':
      console.log('Account frozen. Reason:', error.details.reason);
      break;

    case 'daily_limit_exceeded':
      console.log('Daily limit:', error.details.dailyLimit);
      console.log('Used today:', error.details.usedToday);
      break;

    case 'invalid_recipient':
      console.log('Recipient account not found or invalid');
      break;

    default:
      throw error;
  }
}
```

## Webhooks

Subscribe to transaction events to receive real-time notifications when transactions change state.

### Transaction events

| Event | Description |
| --- | --- |
| `transaction.created` | A new transaction has been initiated |
| `transaction.completed` | A transaction has settled successfully |
| `transaction.failed` | A transaction could not be completed |
| `account.balance_updated` | An account balance has changed |

### Subscribing to events

```javascript subscribe-webhooks.js
const webhook = await buburuza.webhooks.create({
  url: 'https://yourapp.com/webhooks/transactions',
  events: [
    'transaction.created',
    'transaction.completed',
    'transaction.failed',
    'account.balance_updated'
  ]
});
```

### Example webhook payload

