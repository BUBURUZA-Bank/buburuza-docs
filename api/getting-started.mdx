---
title: "Developer Quickstart"
description: "Authenticate, read your account, price a payment, and send it — the shortest working path through the API."
---

This walks the same path as the product [Quickstart](/quickstart), over HTTP. It assumes your space is already verified and its payment account is active; until then money-movement calls return `403`.

## 1. Authenticate

Obtain an access token by signing in — see [Authentication](/api/authentication) — then send it on every call:

```bash
export TOKEN="<access-token>"
export BASE="https://<host>/api/v1"

curl "$BASE/app/accounts" -H "Authorization: Bearer $TOKEN"
```

## 2. Find your account and wallets

```bash
curl "$BASE/app/accounts" -H "Authorization: Bearer $TOKEN"
```

Read the account's status before going further. If money movement is not enabled, nothing below will succeed.

```bash
curl "$BASE/app/accounts/<account_id>/wallets" -H "Authorization: Bearer $TOKEN"
```

## 3. Fund the wallet

Ask which funding methods are open, then fetch instructions for the one you want:

```bash
curl "$BASE/app/accounts/<account_id>/funding-methods" -H "Authorization: Bearer $TOKEN"
curl "$BASE/app/wallets/<wallet_id>/deposit-instructions" -H "Authorization: Bearer $TOKEN"
```

Send the money from your side. Inbound funds appear in the transaction list once they clear.

## 4. Price the payment

Never construct a payment without a quote — the amount is not enough to submit one.

```bash
curl "$BASE/app/transfers/fee-preview?source_wallet_id=<wallet_id>&amount=100.00&currency=USD" \
  -H "Authorization: Bearer $TOKEN"
```

The response carries a `fee_quote_id`, the net amount, the fee, and the total to be debited.

## 5. Send it

```bash
curl -X POST "$BASE/app/transfers" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "source_wallet_id": "<wallet_id>",
    "destination": "<destination>",
    "amount": "100.00",
    "currency": "USD",
    "fee_quote_id": "<fee_quote_id>"
  }'
```

<Warning>
  A quote is single-use and expires ten minutes after issue. Submitting against a consumed or lapsed quote fails with `quote_expired` — request a fresh preview rather than retrying the same one.
</Warning>

## 6. Track it

```bash
curl "$BASE/app/transactions?account_id=<account_id>" -H "Authorization: Bearer $TOKEN"
```

## Handling failures

```javascript
const res = await fetch(`${BASE}/app/transfers`, { method: 'POST', headers, body });
const payload = await res.json();

if (!res.ok) {
  switch (payload.code) {
    case 'quote_expired':
      // Price again and resubmit with the new quote.
      break;
    case 'insufficient_funds':
      // Check the wallet's available balance, not its total.
      break;
    default:
      // Codes may originate at the provider — log correlation_id and stop.
      console.error(payload.code, payload.correlation_id);
  }
}
```

Always keep a default branch: the error set is open, and provider codes pass through unchanged.
