# API Quickstart

A minimal integration path, using the API directly.

## 1. Create an account (signup)

```bash
# Start signup — no authentication required
curl -X POST https://app.buburuza.io/api/v1/auth/sign-up/email \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com"}'
```

You receive a one-time code by email. Confirm it to get a **registration token**:

```bash
curl -X POST https://app.buburuza.io/api/v1/auth/sign-up/email/confirmation \
  -H "X-Registration-Token: <registration_token>" \
  -d '{"code": "123456"}'
```

## 2. Enroll a credential

Register a passkey (WebAuthn ceremony) using the registration token, or enroll TOTP as a fallback. After the ceremony your **signup session** is established and you receive an **access token**.

## 3. Onboard your organisation

```bash
# Current onboarding step
curl https://app.buburuza.io/api/v1/app/onboarding/state \
  -H "Authorization: Bearer <access_token>"

# Set the company name
curl -X PATCH https://app.buburuza.io/api/v1/app/onboarding/profile \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"company_name": "Acme Inc."}'

# Start hosted KYB
curl -X POST https://app.buburuza.io/api/v1/app/onboarding/kyb/start \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"country": "CA"}'
```

Poll KYB and payment-account status until the account is active:

```bash
curl https://app.buburuza.io/api/v1/app/onboarding/kyb/status \
  -H "Authorization: Bearer <access_token>"

curl https://app.buburuza.io/api/v1/app/onboarding/payment-account/status \
  -H "Authorization: Bearer <access_token>"
```

## 4. Read your accounts and wallets

```bash
curl https://app.buburuza.io/api/v1/app/accounts \
  -H "Authorization: Bearer <access_token>"
```

The response includes wallet summaries and balances (`available`, `pending`, `hold`).

## 5. Fund and send

```bash
# Funding methods for the account
curl https://app.buburuza.io/api/v1/app/accounts/<account_id>/funding-methods \
  -H "Authorization: Bearer <access_token>"

# Deposit instructions for a wallet (fiat rails or crypto address)
curl https://app.buburuza.io/api/v1/app/wallets/<wallet_id>/deposit-instructions \
  -H "Authorization: Bearer <access_token>"

# Preview a transfer fee, then create the transfer
curl https://app.buburuza.io/api/v1/app/transfers/fee-preview \
  -H "Authorization: Bearer <access_token>" \
  -d '{"source_wallet_id": "…", "destination_wallet_id": "…", "amount_minor": "10000"}'

curl -X POST https://app.buburuza.io/api/v1/app/transfers \
  -H "Authorization: Bearer <access_token>" \
  -d '{"source_wallet_id": "…", "destination_wallet_id": "…", "amount_minor": "10000", "fee_quote_id": "<from preview>"}'
```
